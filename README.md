### 📋 Task Overview
This repository contains all deliverables, documentation, and resources for Task 1 of the ApexPlanet Cybersecurity & Ethical Hacking Internship Program. The task focuses on building strong fundamentals in cybersecurity, networking, cryptography, and setting up a professional penetration testing lab environment.

---

### 🎯 Learning Objectives
- Understand core cybersecurity principles (CIA Triad, threat types, attack vectors)
- Set up a complete penetration testing lab environment
- Master Linux command-line fundamentals
- Learn networking basics (OSI Model, TCP/IP, DNS, HTTP/HTTPS)
- Understand cryptography concepts and implementations
- Familiarize with essential security tools

### 📚 Key Topics Covered
1. **Cybersecurity Basics**
   - CIA Triad
   - Common threats (Phishing, Malware, DDoS, SQL Injection)
   - Attack vectors (Social Engineering, Wireless Attacks, Insider Threats)

2. **Lab Environment Setup**
   - VirtualBox installation and configuration
   - Kali Linux setup
   - Metasploitable2 deployment
   - Network configuration (Host-only adapter)

3. **Linux Fundamentals**
   - File system navigation
   - File permissions and ownership
   - Package management
   - Networking commands

4. **Networking Basics**
   - OSI Model (7 layers)
   - TCP/IP Protocol Suite
   - DNS, HTTP, HTTPS
   - IP Addressing, Subnetting, NAT

5. **Cryptography**
   - Symmetric vs Asymmetric encryption
   - Hashing algorithms (MD5, SHA-256)
   - Digital certificates and SSL/TLS
   - Hands-on with OpenSSL

6. **Security Tools**
   - Wireshark (Packet analysis)
   - Nmap (Network scanning)
   - Burp Suite (Web app testing)
   - Netcat (Network utility)
